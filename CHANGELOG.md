# Changelog

## 0.4.0 — VoxPanel

- Nama dan ikon VoxPanel.
- Target serta efek yang terbaca ditandai pada layar utama.
- Target WA/ML dapat dipilih dari panel mengambang.
- Posisi panel disimpan terpisah untuk portrait dan landscape.
- Parser vendor memisahkan status tidak dikenal dari Normal dan menolak paket/nomor efek di luar dukungan.
- Reset diverifikasi sebelum melanjutkan pergantian target.
- Gradle wrapper, Android Studio project, unit tests, CI, dan dokumentasi portofolio/privasi.

## 0.3

- Tampilan gelap, status vendor, foreground service, panel mengambang yang dapat digeser.
- Pengguna melaporkan panel berfungsi dan lancar pada perangkat uji.

## 0.2

- Target WhatsApp dan Mobile Legends; nama efek berdasarkan uji pengguna.
- Pengguna melaporkan suara berubah di panggilan WhatsApp dan permainan ML.

## 0.1
